Como usar
1. Crie um novo projeto clicando em "+ Novo" na barra acima.
2. Preencha as fases DMAIC sequencialmente pelo menu lateral.
3. Salve a qualquer momento — os dados ficam no navegador.
4. Exporte como arquivo .json para backup ou compartilhamento.
5. Importe projetos de outros dispositivos ou colaboradores.
6. Use as Ferramentas CEP para análises estatísticas da fase Measure.
